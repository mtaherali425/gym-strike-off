# Gym Strike-Off Calendar — iPhone PWA

## Install on iPhone using Chrome
1. The app must be served from an HTTPS website (or a local development server).
2. Open `index.html` from that HTTPS address in Chrome on iPhone.
3. Tap **Share**.
4. Choose **Add to Home Screen**.
5. Tap **Add**.
6. Launch **Gym Strike-Off** from the Home Screen.

The app works offline after its first successful load and keeps gym data in browser local storage.

## Files
- `index.html` — app
- `manifest.webmanifest` — PWA metadata
- `sw.js` — offline service worker
- `icons/` — app icons
